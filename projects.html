STM32 Audio Player with Custom PCB

May 2026

Built an embedded system audio player using the STM32F429I-DISC1 development board and STM32CubeIDE. Developed C firmware to read WAV files from an SD card and stream audio through the microcontroller's digital-to-analog converter. Designed a custom PCB expansion board to support audio output, combining embedded software with hands-on hardware development.

Key Features

  • SD card file access using FatFs and the SDIO interface
  • 16-bit mono PCM WAV playback with conversion to 12-bit DAC samples
  • Timer-triggered audio output using DMA and buffer refill tasks
  • UART commands for listing files, playing, pausing, resuming, and seeking
  • FreeRTOS tasks, queues, and semaphores to coordinate playback and commands
  • SD card insertion and removal detection
  • Custom PCB expansion board for audio output
