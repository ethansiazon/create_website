# Ethan Siazon - Personal Portfolio

This repository contains my personal portfolio website created for CS 3365 - Software Engineering at Texas Tech University.

The portfolio highlights my background as a Computer Engineering student, technical skills, academic and professional experience, and engineering projects. The website was developed while practicing Git and GitHub workflows including feature branches, incremental commits, merging, pushing, pulling, and deployment through GitHub Pages.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Font Awesome

## Portfolio Content

The website includes:

- Home / Introduction
- About Me
- Technical Skills
- Engineering Projects
- Professional Experience
- Contact and Social Links

Featured projects include work involving embedded systems, computer vision, FPGA development, robotics, artificial intelligence, and semiconductor manufacturing.

## Repository Structure

